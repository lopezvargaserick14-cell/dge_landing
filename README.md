# DGE Studio · Landing Page de Captación y Cine Publicitario

Landing page de alta conversión para **DGE Studio** (Bucaramanga, Santander), productora audiovisual especializada en captación de clientes de alto ticket para los sectores de Glampings, Clínicas Odontológicas y Proyectos Inmobiliarios.

Proyecto desarrollado como parte del **Taller Práctico: Creación de Propuestas y Maquetaciones Web con Inteligencia Artificial (Prompt Engineering)**.

---

## 🚀 Características Principales

* **Hero Cinematográfico:** Video en bucle de alto impacto con superposición de viñeta oscura y acentos en oro pulido.
* **Vitrina de Reels Verticales (9:16):** Reproductor interactivo diseñado para simular pauta publicitaria en Instagram/TikTok.
* **Cotizador Interactivo en Tiempo Real:** Cálculo dinámico de presupuestos con descuentos progresivos y precios psicológicos impares ($159.900, $679.900 y $1.279.900 COP).
* **Integración a WhatsApp:** Conexión directa hacia el canal comercial (+57 320 835 3796) con mensaje pre-rellenado y codificado según las opciones elegidas por el prospecto.
* **Diseño 100% Responsivo:** Optimizado para dispositivos móviles (360 px), tablets (768 px) y monitores de escritorio (1200 px o superior).
* **0 Errores en Consola:** Código JavaScript nativo, limpio y validado.

---

## 🛠️ Tecnologías Empleadas

* **HTML5 Semántico:** Estructuración accesible (`header`, `nav`, `main`, `section`, `article`, `footer`).
* **CSS3 Moderno:** Variables nativas en `:root`, efectos glassmorphism (`backdrop-filter`), CSS Grid y Flexbox.
* **JavaScript ES6+:** Manipulación del DOM, delegación de eventos y cálculo dinámico sin dependencias externas.
* **Herramientas de IA y Skills:** Documentación con `ui-ux-pro-max-skill`, `find-skills` y Pexels API.
